Project Overview

This repository demonstrates Git branching, merging, and collaboration workflows for the Software Development Practice (SDP) course.

Core Features

  • Feature Branch Isolation (feature branch workflow)
  • Seamless Multi-branch Collaboration and Merging
  • Integrated Merge History with Non-Fast-Forward Commits
  • Production-grade .gitignore Configuration
  • Auditable Commit and Undo History (git reset & git revert)
